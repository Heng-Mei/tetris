# TETRIS · modern

零依赖、纯前端的现代俄罗斯方块。手感参数、键位、踢墙与旋转系统全部可调，设置存本地。

## 运行

```bash
python3 -m http.server 8123
```

打开 http://localhost:8123

（必须用 http 起服务，ES Module 不能走 file://。）

## 操作

默认键位（设置面板里可改）：

| 动作 | 键 |
| --- | --- |
| 左/右移 | ← / → |
| 软降 | ↓ |
| 硬降 | Space |
| 顺时针 / 逆时针 | ↑ / Z |
| 180° | A |
| Hold | C |
| 暂停 | Esc |
| 重开 | R |
| 开始 | Enter |

## 可调项

- **DAS / ARR / SDF**：DAS 蓄力延迟、ARR 连发间隔（0 = 瞬间贴墙）、软降倍率（软降速度 = 重力 × 倍数）
- **锁定延迟 / 最大重置次数 / 移动、旋转是否重置锁定**
- **重力（行/秒）、ARE 出生延迟、消行延迟**
- **IRS / IHS**：出生前旋转 / Hold
- **旋转取消 DAS 蓄力、双向键后按优先**
- **旋转系统**：SRS / ARS / Classic，或粘贴 JSON 自定义
- **180°**：关闭 / 两步旋转 / 踢墙表
- **键位重绑**、**预设**（Modern / TGM / Classic）、**导入导出 JSON**

时间逻辑跑固定 60Hz 步长，渲染走 rAF，所以 DAS/ARR 的毫秒语义与显示器刷新率无关。

## 自定义旋转系统

设置面板 →「自定义旋转系统」→「打开编辑器」，全程图形化，不直接编辑 JSON：

- 7 个方块 × 4 个旋转状态，点格子绘制
- 每个方块单独设置出生 X/Y
- 踢墙表分「通用 / I 块 / 180°」；通用与 I 块按 8 个旋转方向分别配置偏移，按顺序尝试
- 可一键载入 SRS / ARS / Classic 作为模板
- 「导出 JSON」下载 `rotation-system.json`；「导入 JSON」从文件恢复（界面不展示 JSON 文本）

导出/导入的 JSON 结构：

```json
{
  "name": "My Rotation",
  "shapes": { "I": ["四个旋转状态的格子数组"], "...": [] },
  "spawn": { "I": [3, 2] },
  "kicks": {
    "standard": { "0>1": [[0, 0], [-1, 0]] },
    "I": { "0>1": [[0, 0]] },
    "half": [[0, 0], [0, -1]]
  }
}
```

- 坐标是盒内 `[x, y]`，y 向下；状态 0=初始，1=顺时针，2=180，3=逆时针。
- `kicks.standard` / `kicks.I` 按 `"起>止"` 取偏移数组，`"*"` 可作兜底；`kicks.half` 是 180° 表。
- O 块永远不踢墙。

## 已知取舍

- ARS 采用 Arika 踢墙规则（基础→右 1→左 1，I 不踢墙），形状沿用 SRS 而非严格 Sega 形状。
- SRS 的 180° 使用通用踢墙表，不是 TETR.IO 的精确 SRS+ 表；可用自定义系统覆盖。
- 消行用整体闪白动画，不做逐行清除动画。
