# TETRIS · modern

零依赖、纯前端的现代俄罗斯方块。Marathon / Sprint 40L / Blitz 2:00 / 人机对战，手感参数、键位、踢墙、旋转系统与攻击表全部可调，设置存本地。

## 运行

```bash
python3 -m http.server 8123
```

打开 http://localhost:8123

（必须用 http 起服务，ES Module 不能走 file://。）

## 操作

默认键位（设置面板里可改）：

| 动作 | 键 |
| --- | --- |
| 左/右移 | ← / → |
| 软降 | ↓ |
| 硬降 | Space |
| 顺时针 / 逆时针 | ↑ / Z |
| 180° | A |
| Hold | C |
| 暂停 | Esc |
| 重开 | R |
| 开始 | Enter |

## 可调项

- **DAS / ARR / SDF**：DAS 蓄力延迟、ARR 连发间隔（0 = 瞬间贴墙）、软降倍率（软降速度 = 重力 × 倍数）
- **锁定延迟 / 最大重置次数 / 移动、旋转是否重置锁定**
- **重力（行/秒）、ARE 出生延迟、消行延迟**
- **IRS / IHS**：出生前旋转 / Hold
- **旋转取消 DAS 蓄力、双向键后按优先**
- **旋转系统**：SRS / ARS / Classic，或图形化自定义
- **180°**：关闭 / 两步旋转 / 踢墙表
- **键位重绑**、**预设**（Modern / TGM / Classic）、**导入导出 JSON**

时间逻辑跑固定 60Hz 步长，渲染走 rAF，所以 DAS/ARR 的毫秒语义与显示器刷新率无关。

## 游戏模式

顶栏切换模式，切换会立即重开：

| 模式 | 规则 | 结束 |
| --- | --- | --- |
| Marathon | 无尽 | 顶死 |
| Sprint 40L | 从开局正计时，目标 40 行 | 消满 40 行显示用时；顶死判失败 |
| Blitz 2:00 | 2 分钟倒计时冲分；每 10 行升 1 级，重力取用户重力与 `1 + (level-1)×0.6` 的较大值 | 时间到按分数结算；顶死提前结束 |
| VS AI | 双方各自消行、互发垃圾行；AI 简单 / 普通 / 困难 | 任一方顶死；同帧双顶死判玩家负 |

Sprint / Blitz 的计时包含出生与消行延迟；暂停、切后台、打开设置抽屉时停止。

## 人机对战

- 每次锁定先按攻击表算出攻击，抵消自己的待接收垃圾，剩余发给对方，然后把自己剩余的待接收垃圾从底部插入。
- 垃圾行每行 1 个空洞，连续行避免同洞；被推入顶部隐藏行即顶死。
- AI 用一层启发式落点搜索（消行、总高度、空洞、崎岖度、最大高度），难度只调落子间隔与失误率；不做 Hold、不做 T-Spin 做局。
- 右栏显示 AI 棋盘、待接收与累计攻击；左栏 HUD 显示玩家攻击与待接收。

## 攻击表

设置面板 →「攻击表」→「打开编辑器」：

- 单消 / 双消 / 三消 / Tetris、T-Spin Mini / 单 / 双 / 三、Perfect Clear 的基础攻击值
- B2B 加成与 combo 表（首消为 0，超出长度重复最后一项）
- 预设 Guideline / 高攻击 / 低攻击；导入/导出 `attack-table.json`
- 界面不显示 JSON 文本，只在导出时产出文件

## 自定义旋转系统

设置面板 →「自定义旋转系统」→「打开编辑器」，全程图形化，不直接编辑 JSON：

- 7 个方块 × 4 个旋转状态，点格子绘制
- 每个方块单独设置出生 X/Y
- 踢墙表分「通用 / I 块 / 180°」；通用与 I 块按 8 个旋转方向分别配置偏移，按顺序尝试
- 可一键载入 SRS / ARS / Classic 作为模板
- 「导出 JSON」下载 `rotation-system.json`；「导入 JSON」从文件恢复（界面不展示 JSON 文本）

导出/导入的 JSON 结构：

```json
{
  "name": "My Rotation",
  "shapes": { "I": ["四个旋转状态的格子数组"], "...": [] },
  "spawn": { "I": [3, 2] },
  "kicks": {
    "standard": { "0>1": [[0, 0], [-1, 0]] },
    "I": { "0>1": [[0, 0]] },
    "half": [[0, 0], [0, -1]]
  }
}
```

- 坐标是盒内 `[x, y]`，y 向下；状态 0=初始，1=顺时针，2=180，3=逆时针。
- `kicks.standard` / `kicks.I` 按 `"起>止"` 取偏移数组，`"*"` 可作兜底；`kicks.half` 是 180° 表。
- O 块永远不踢墙。

## 已知取舍

- ARS 采用 Arika 踢墙规则（基础→右 1→左 1，I 不踢墙），形状沿用 SRS 而非严格 Sega 形状。
- SRS 的 180° 使用通用踢墙表，不是 TETR.IO 的精确 SRS+ 表；可用自定义系统覆盖。
- 消行用整体闪白动画，不做逐行清除动画。
- AI 只做一层评估，不会 Hold、不会做 T-Spin，也不会主动留四消；困难档靠落子速度而非更强搜索。
- 垃圾行空洞随机，只避免相邻行同洞，不实现 per-column 计数或 messiness。
- Blitz 的重力曲线固定，不开放自定义。
- 对手棋盘放在右栏，尺寸小于主棋盘，不做等宽分屏或移动端专用布局。
