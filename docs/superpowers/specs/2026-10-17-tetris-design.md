# 现代俄罗斯方块 — 设计

日期：2026-10-17
状态：已确认，实施中

## 目标

本地运行的单页俄罗斯方块，核心是**手感可调**而非框架。无构建步骤、无第三方依赖，浏览器直接跑。

范围内：ARR/DAS/SDF、锁定延迟、重力、踢墙、旋转系统、180°、IRS/IHS、键位重绑、预设、设置导入导出。
范围外：联机、回放、排行榜、自定义板宽板高、触屏、皮肤音效。

## 架构

```
index.html
css/style.css
js/main.js        启动、固定步长主循环、装配
js/engine.js      棋盘/落子/消行/7-bag/计分/T-Spin 判定（纯逻辑）
js/handling.js    DAS/ARR 输入状态机（纯逻辑）
js/rotations.js   旋转系统数据表（形状 + kick 表）
js/settings.js    默认值、预设、校验、localStorage、导入导出
js/input.js       键位映射、重绑、按下/松开分发
js/render.js      Canvas 2D 绘制
js/ui.js          设置面板生成
test/engine.test.mjs
```

引擎与手势逻辑不碰 DOM，可直接在 Node 里测试。

## 计时模型

- 逻辑固定 60Hz（`1000/60` ms）accumulator；渲染走 `requestAnimationFrame`。
- 所有手感参数以毫秒暴露，跨刷新率语义一致。
- 主循环每帧最多补 6 个逻辑步，避免切后台回来时追帧爆炸。

## 输入 / 手感

- DAS 蓄力完成后立即移动一次，之后按 ARR 连发；ARR = 0 时一步贴墙。
- 双向键同时按住：后按优先（可关）；释放后回落到仍按住的方向。
- 软降速度 = `重力 × SDF`；软降每格 +1 分。
- 锁定延迟从触底开始计时；移动/旋转按开关与次数上限重置。
- IRS/IHS 在 `spawning` 阶段缓存，出生后立即执行。
- 180° 三档：关闭 / 两步（连续两次顺时针，失败回滚）/ 踢墙表。

## 旋转系统

旋转系统是数据：`shapes`（7 块 × 4 态，盒内坐标、y 向下）+ `spawn` + `kicks`。
kick 数组按顺序取第一个不碰撞的偏移；`"*"` 为兜底；O 块不踢墙。

内置：

- **SRS**：完整 5 次踢墙测试，I 块独立表。
- **ARS**：基础旋转 → 右 1 → 左 1；I 不踢墙；形状沿用 SRS（不实现严格 Sega 形状）。
- **Classic**：无踢墙。
- **Custom**：设置面板粘 JSON，形状/出生点/kick 表可覆盖，校验失败保留原配置。

180° 默认两步；「踢墙表」模式使用 `kicks.half`（SRS 内置通用表，非 TETR.IO 精确表）。

## 规则与计分

- 10 宽 × 20 可见行 + 2 行隐藏缓冲区；固定 7-bag。
- Hold 每块一次；Next 显示 5 个。
- Guideline 计分：Single 100 / Double 300 / Triple 500 / Tetris 800；T-Spin（三格判定，分 mini）与 Combo、B2B ×1.5；等级 = 消行 / 10 + 1，作为倍率。
- 重力由玩家设定，等级不加自动加速（避免和自定义重力冲突）。
- 出生碰撞即游戏结束（不做 lock-out 特判）。

## UI

- 左：Hold + 分数/消行/等级/时间/PPS/B2B。
- 中：棋盘（网格、幽灵、发光当前块、消行闪白）。
- 右：Next ×5 + 提示。
- 设置抽屉：滑杆即时生效、开关、旋转系统下拉、键位点按重绑、自定义旋转 JSON、导入导出、恢复默认。
- 预设：Modern / TGM / Classic。
- 视觉：深色 + 青/紫点缀，圆角、字距、tabular-nums。

## 持久化与错误处理

- `localStorage['tetris.settings.v1']`，缺失/损坏时回退默认值。
- 导入文件不是合法 JSON 或结构不对 → toast 报错，不改当前设置。
- 自定义旋转系统结构错误 → 拒绝应用并保留上一个系统。
- 切后台自动暂停并清空按住状态。

## 验证

`node --test`：7-bag 分布、碰撞/幽灵、SRS 贴底踢墙、T-Spin 判定与计分、消行压缩、DAS/ARR 时序、ARR 0 贴墙、180° 关闭、软降 + 锁定延迟。

手动：`python3 -m http.server 8123` 打开页面，验证移动/旋转/硬降/Hold/消行/暂停/设置即时生效/刷新后设置保留。

## 已知取舍

- 逐行消除动画改为整体闪白。
- ARS 形状非严格 Sega；SRS 180 表为通用表。
- 移动端布局只做基础收缩，不做触屏操控。
